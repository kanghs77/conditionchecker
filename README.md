# 컨디션 체커

매일 정해진 시각에 알림이 울리고, 알림을 누르면 질문이 한 화면에 하나씩 나오는 컨디션 기록 앱입니다.
쌓인 기록은 CSV나 LLM 분석용 파일로 내보내서, 어떤 습관이 몸·정신 상태와 집중도에 영향을 주는지 분석할 수 있습니다.

## 기능

- **매일 알림**: 알림 시각을 여러 개 정할 수 있고, 언제든 바꿀 수 있습니다. 알림을 누르면 바로 설문이 열립니다.
- **한 화면에 질문 하나**: 예/아니오와 점수는 누르면 바로 다음 질문으로 넘어갑니다. 이전으로 돌아가거나 건너뛸 수 있습니다.
- **질문 직접 편집**: 형식은 예/아니오, 점수(범위 지정), 숫자(단위 지정), 객관식, 자유 메모 중에서 고릅니다.
  - 질문마다 **역할**을 정합니다. 영향 요인은 수면·물·운동처럼 원인 후보이고, 결과 지표는 컨디션·기분·집중도처럼 개선하고 싶은 상태입니다. LLM이 무엇이 무엇에 영향을 주는지 분석할 때 이 구분을 씁니다.
  - 질문을 끄면 기록은 남고 설문에서만 빠집니다. 답변이 있는 질문을 삭제해도 과거 데이터는 내보내기에 남습니다.
- **날짜별 저장**: 하루에 기록 1개를 저장합니다. 지난 날짜를 나중에 채우거나 수정할 수 있습니다. 답할 때마다 바로 저장되므로 도중에 닫아도 입력한 답은 사라지지 않습니다.
- **내보내기**
  - `LLM 분석용 .md`: 분석 요청문, 변수 설명, 일별 데이터가 한 파일에 들어 있습니다. 그대로 첨부하면 됩니다.
  - `일별 표 CSV`: 날짜 1행 × 질문 1열 형태입니다.
  - `전체 응답 원본 CSV`: 답변 1개가 1행이고, 응답 시각까지 들어 있습니다.
  - `질문 목록 CSV`, `전체 백업 JSON`

## 실행 방법

1. 휴대폰에 **Expo Go** 앱을 설치합니다 (App Store / Google Play).
2. PC에서 다음을 실행합니다.
   ```bash
   npm install
   npx expo start
   ```
3. 화면에 나온 QR 코드를 휴대폰으로 스캔합니다.

알림은 휴대폰에 예약되는 로컬 알림이라서 서버가 필요 없습니다. 모든 데이터는 휴대폰 안의 SQLite에만 저장됩니다.

Expo Go 없이 독립된 앱으로 설치하려면 [EAS Build](https://docs.expo.dev/build/introduction/)로 빌드합니다.

## 구조

| 파일 | 역할 |
|---|---|
| `App.tsx` | 탭과 설문 모달, 알림을 눌렀을 때의 처리 |
| `src/db.ts` | SQLite 스키마와 CRUD (`questions`, `entries`, `answers`, `reminders`) |
| `src/notifications.ts` | 매일 알림 예약과 권한 요청 |
| `src/export.ts` | CSV, Markdown, JSON 내보내기 |
| `src/defaultQuestions.ts` | 처음 설치할 때 들어가는 예시 질문 |
| `src/screens/*` | 홈/기록, 설문, 질문 편집, 알림·내보내기 화면 |
